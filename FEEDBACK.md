# Обратная связь: приложение → сайт → админ-панель

В приложении (Android и iOS) есть вкладка **«Связь»**: пользователь пишет
сообщение и при желании оставляет контакт. Отправка — обычный HTTPS `POST`
с JSON на сайт **oiltechclean.ru**, без почтовых клиентов и без токенов
внутри приложения.

## Схема

```
Приложение ──POST JSON──▶ https://oiltechclean.ru/feedback_api.php
                                   │
                                   ├─▶ data/feedback.json (хранилище отзывов)
                                   └─▶ Админ-панель сайта → вкладка «Отзывы из приложения»
```

## Состав реализации

| Часть | Файл | Назначение |
|---|---|---|
| Приёмник | `feedback_api.php` (корень сайта) | приём отзывов, список/прочтение/удаление для админки |
| Хранилище | `data/feedback.json` | отзывы в JSON, папка закрыта `.htaccess` от веба |
| Админ-модуль | `Admin/feedback.js` | вкладка «Отзывы из приложения» |
| Подключение вкладки | `Admin/index.html`, `Admin/admin.js` | кнопка вкладки и ленивая загрузка модуля |
| Android | `app/src/main/java/ru/oiltechclean/assistant/data/FeedbackConfig.kt` | адрес приёмника |
| iOS | `iosApp/iosApp/Services/FeedbackService.swift` | адрес приёмника |

Адрес приёмника в обеих платформах уже задан:

```
https://oiltechclean.ru/feedback_api.php
```

## Тело запроса (одинаковое на Android и iOS)

```json
{
  "type": "feedback",
  "message": "Текст пожелания",
  "contact": "Телефон, e-mail или «—»",
  "app": "OilTech Assistant",
  "platform": "Android",
  "appVersion": "1.1",
  "sentAt": "2026-11-21T08:00:00Z"
}
```

Успешный ответ — `200 OK`:

```json
{ "success": true, "message": "Спасибо! Отзыв получен." }
```

Ошибки: `422` — сообщение короче 5 символов, `429` — слишком частые отправки,
`413` — слишком большое тело, `500` — не удалось сохранить.

## Админ-панель

1. Открыть `https://oiltechclean.ru/Admin/` и войти под логином админки новостей.
2. Вкладка **«Отзывы из приложения»** (`/Admin/?tab=feedback`) — список отзывов,
   счётчик новых, кнопки «Прочитано / В новые» и «Удалить».
3. Авторизация — общая сессия `otc_admin` (та же, что у новостей и заказов),
   токены между приложением и сайтом не передаются.

## Защита

- `data/.htaccess` закрывает папку данных от прямого доступа из веба.
- Список, отметка «прочитано» и удаление требуют активной сессии админки (`401` без неё).
- Ограничение частоты: не более 5 отзывов с одного IP за 10 минут.
- Honeypot-поле `website`: если оно заполнено, запрос считается ботом и отбрасывается.
- Ограничения длины: сообщение — 4000 символов, контакт — 200, тело запроса — 16 КБ.
- В JSON не сохраняются лишние данные о пользователе: в админку отдаются только
  текст, контакт, платформа, версия и даты (IP и User-Agent остаются в файле для разбора спама).

## Что загрузить на хостинг

```
feedback_api.php        (новый файл в корне сайта)
data/feedback.json      (файл с [] и правами на запись; создаётся автоматически)
data/.htaccess          (уже есть, закрывает папку данных)
Admin/index.html        (обновлённая вкладка)
Admin/admin.js          (регистрация API и модуля)
Admin/feedback.js       (модуль вкладки)
```

Права: папка `data/` должна быть доступна PHP на запись (как для `news.json`
и `projects.json`). После загрузки проверить, что папка данных не открывается
по прямой ссылке `https://oiltechclean.ru/data/feedback.json` (должен быть `403`).

Приложение начнёт отправлять отзывы на сайт только после пересборки
и публикации новой версии APK/IPA — адрес приёмника зашит в код.

## Проверка

Публичная отправка (без авторизации):

```bash
curl -i -X POST https://oiltechclean.ru/feedback_api.php \
  -H "Content-Type: application/json" \
  -H "Accept: application/json" \
  -d '{"type":"feedback","message":"Проверка формы","contact":"—","app":"OilTech Assistant","platform":"test","appVersion":"1.1","sentAt":"2026-11-21T08:00:00Z"}'
```

Ожидаемо: `200` и `{"success":true,...}`, после чего отзыв появится
в админ-панели. Проверка защиты без входа:

```bash
curl -i "https://oiltechclean.ru/feedback_api.php?action=list"
```

Ожидаемо: `401` и `{"success":false,"message":"Нужна авторизация"}`.

## Альтернативы приёмника

Приёмник — обычный HTTPS POST с JSON, поэтому адрес можно заменить без
изменения логики экрана:

| Вариант | Плюсы | Минусы |
|---|---|---|
| Свой `feedback_api.php` (текущий) | бесплатно, отзывы сразу в админке сайта | нужен PHP-хостинг (он есть) |
| Formspree / Getform | без сервера | отзывы в чужом кабинете, лимиты бесплатного тарифа |
| Cloudflare Worker → Telegram Bot | мгновенные уведомления | нужен Worker и токен бота на сервере |
| Google Apps Script → Google Sheets | заявки в таблице | настройка через скрипт-редактор |

Важно: не встраивайте в приложение токен Telegram-бота или приватный ключ —
он извлекается из APK/IPA. Приложение должно знать только публичный URL приёмника.
