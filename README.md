# ⚡ OilTech Assistant

**Профессиональный карманный инструмент для энергетиков, полевых инженеров и сервисных бригад**, работающих с трансформаторным маслом и маслоочистительным оборудованием производства **«ОИЛТЕХКЛИН»** (установки **УВСМ, ЦУМ, БРМ, БВН, УФМ**).

> 📴 **100% Offline-First:** Приложение разработано специально для работы на подстанциях, ТЭЦ и промышленных объектах в условиях полного отсутствия связи. Все расчеты, справочники, алгоритмы и базы данных доступны локально без интернета.

---

## 🚀 Основные возможности

### 🧮 Инженерные калькуляторы (офлайн)
* **Дегазация и сушка масла:** расчет количества циклов и времени обработки для установок типа **УВСМ**.
* **Расчет сорбентов:** определение необходимой массы цеолита и силикагеля для блоков **ЦУМ** и **БРМ**.
* **Вакуумирование:** расчет времени вакуумирования баков силовых трансформаторов для блоков **БВН**.
* **Температурная коррекция:** пересчет тангенса угла диэлектрических потерь ($\text{tg}\,\delta$) к стандартной температуре.
* **Конвертер величин:** быстрый перевод инженерных единиц (давление, влагосодержание, объемный расход и др.).

### 🔬 Диагностика и нормативная база
* **Экспресс-расшифровка ХАРГ:** анализ растворенных в масле газов для оперативного выявления внутренних дефектов трансформатора.
* **Справочник нормативов (ГОСТ и РД):** предельно допустимые значения показателей качества трансформаторного масла для классов напряжения **от 6 до 750 кВ**.

### 🛠 Эксплуатация оборудования «ОИЛТЕХКЛИН»
* **База оборудования:** полный справочник технических характеристик установок (**УВСМ, ЦУМ, БРМ, БВН, УФМ**).
* **Предпусковые чек-листы:** интерактивные пошаговые проверки перед запуском, защищающие оборудование от ошибок персонала.
* **Устранение неисправностей (Troubleshooting):** база типовых сбоев с готовыми пошаговыми алгоритмами их решения прямо на объекте.

### 📋 Полевой журнал и PDF-отчетность
* **Локальная история замеров:** ведение журнала и сохранение данных по каждому трансформатору в памяти устройства.
* **Генерация PDF-протоколов в 1 клик:** автоматическое формирование официального отчета о выполненных работах со сравнением показателей **«ДО»** и **«ПОСЛЕ»** обработки.
* **Быстрый экспорт:** отправка готовых протоколов в мессенджеры или на электронную почту при появлении сети.

## 🏭 Поддерживаемое оборудование

| Серия / Блок | Назначение в приложении |
| :--- | :--- |
| **УВСМ** | Расчет циклов и времени дегазации/сушки, ТТХ, чек-листы, диагностика |
| **ЦУМ** | Расчет массы сорбентов (цеолит, силикагель), справочник, сервис |
| **БРМ** | Расчет сорбентов для регенерации масла, инструкции по эксплуатации |
| **БВН** | Расчет времени вакуумирования баков трансформаторов, ТТХ, сервис |
| **УФМ** | Справочник технических характеристик, предпусковые проверки |
