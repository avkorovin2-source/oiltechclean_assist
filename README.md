
 OilTech Assistant

Профессиональный офлайн-инструмент для энергетиков и сервисных бригад, обслуживающих трансформаторное масло и оборудование «ОИЛТЕХКЛИН» (установки УВСМ, ЦУМ, БРМ, БВН, УФМ).

🚀 Основные возможности

• Инженерные калькуляторы: расчет циклов дегазации/сушки (УВСМ), массы сорбентов (ЦУМ, БРМ), вакуумирования баков (БВН), коррекции тангенса потерь (tg δ) и конвертер величин.
• Диагностика и нормативы: расшифровка растворенных газов (ХАРГ), Треугольник Дюваля 1 и справочник ГОСТ/РД (РД 34.45-51.300-97, ГОСТ 982-80 для сетей 6–750 кВ).
• Эксплуатация и сервис: каталог характеристик установок, предпусковые интерактивные чек-листы и база устранения неисправностей.
• Полевой журнал: локальное сохранение замеров по трансформаторам и формирование протоколов сравнения «ДО / ПОСЛЕ» с экспортом.

🏭 Поддерживаемое оборудование


Серия / Блок	Назначение в приложении
УВСМ	Расчет циклов и времени дегазации/сушки, ТТХ, чек-листы, диагностика
ЦУМ	Расчет массы сорбентов (цеолит NaA), справочник, сервис
БРМ	Расчет сорбентов (силикагель КСКГ) для регенерации масла, инструкции
БВН	Расчет времени вакуумирования баков трансформаторов, ТТХ, сервис
УФМ	Справочник технических характеристик, предпусковые проверки


🛠 Технологический стек и архитектура

• Платформа: Android (API 26–35 / Android 8.0+), Kotlin 2.0, Jetpack Compose, Material 3, Gradle (Kotlin DSL), Java 17.
• Пакет: ru.oiltechclean.assistant (100% автономная работа без доступа в интернет).
• Структура проекта: разделение на пакеты ui/ (экраны калькуляторов, диагностики, оборудования, журнала), domain/ (инженерные формулы и алгоритмы ХАРГ), data/ (офлайн-репозитории) и model/.

## 📐 Нормативная база и инженерные алгоритмы

Все расчеты и диагностические алгоритмы в приложении опираются на действующие отраслевые стандарты энергетики:

* **Диагностика ХАРГ (РД 153-34.0-46.302-00 и IEEE C57.104-2019):**
  * Контроль граничных концентраций газов ($\text{H}_2, \text{CH}_4, \text{C}_2\text{H}_2, \text{C}_2\text{H}_4, \text{C}_2\text{H}_6$).
  * Автоматическое определение зоны дефекта по **Треугольнику Дюваля 1** (`PD`, `T1`, `T2`, `T3`, `DT`, `D1`, `D2`).
  * Оценка термической деструкции бумажной (твёрдой) изоляции по соотношению $\text{CO}_2 / \text{CO} \ge 13$.
  * Расчёт скорости нарастания концентраций газов ($\text{ppm/сут}$).
* **Нормы качества масла (РД 34.45-51.300-97 и ГОСТ 982-80):**
  * Встроенные таблицы предельно допустимых значений (пробивное напряжение, влагосодержание, газосодержание, кислотное число, $\text{tg}\,\delta$ при $90\,^\circ\text{C}$) как для **масла в эксплуатации**, так и для **свежего масла перед заливкой** (классы напряжения от 6 до 750 кВ).
* **Теплофизические и вакуумные расчёты:**
  * Пересчёт тангенса угла диэлектрических потерь ($\text{tg}\,\delta$) к целевой температуре по экспоненциальной зависимости.
  * Расчёт времени вакуумирования баков трансформаторов (БВН) с учётом свободного объёма, быстродействия насосов и остаточного давления.
