OilTech Assistant — профессиональный карманный инструмент для энергетиков, полевых инженеров и сервисных бригад, работающих с трансформаторным маслом и маслоочистительным оборудованием производства «ОИЛТЕХКЛИН» (установки УВСМ, ЦУМ, БРМ, БВН, УФМ).
Приложение разработано специально для работы на подстанциях, ТЭЦ и промышленных объектах в условиях полного отсутствия интернета. Все расчеты, справочники и базы данных доступны 100% офлайн.

Основные возможности приложения:

• Инженерные калькуляторы (офлайн):
	• Расчет циклов и времени дегазации/сушки масла для установок типа УВСМ.
	• Расчет необходимой массы сорбентов (цеолит, силикагель) для блоков ЦУМ и БРМ.
	• Расчет времени вакуумирования баков трансформаторов (блоки БВН).
	• Температурная коррекция параметров (пересчет тангенса угла диэлектрических потерь \(\operatorname{tg}\delta\) к стандартной температуре).
	• Инженерный конвертер единиц измерения (давление, влагосодержание, объемный расход).
• Диагностика и нормативная база:
	• Экспресс-расшифровка хроматографического анализа растворенных газов (ХАРГ) для выявления дефектов внутри трансформатора.
	• Справочник предельно допустимых значений показателей качества масла по ГОСТ и РД для классов напряжения от 6 до 750 кВ.
• Эксплуатация оборудования «ОИЛТЕХКЛИН»:
	• Справочник технических характеристик установок.
	• Интерактивные предпусковые чек-листы для защиты оборудования от ошибок при запуске.
	• База типовых неисправностей с пошаговыми алгоритмами их устранения на объекте.
• Полевой журнал и PDF-отчеты:
	• Локальное сохранение истории замеров по каждому трансформатору прямо в памяти смартфона.
	• Формирование готового официального PDF-протокола выполненных работ (сравнение показателей «ДО» и «ПОСЛЕ» обработки) в один клик с возможностью отправки в мессенджеры или на почту.
